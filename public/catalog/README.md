`OpenNGC.csv` is the NGC/IC object database maintained by Mattia Verga and contributors. Attribution: OpenNGC by Mattia Verga and contributors, https://github.com/mattiaverga/OpenNGC. OpenNGC combines data from NASA/IPAC NED, HyperLEDA, CDS/SIMBAD, HEASARC and Harold Corwin's NGC/IC position work. The source CSV retains its per-row `Sources` field. Explorer Sense reads the CSV locally, filters rows with valid coordinates, and shows at most 50 search results at a time.

This file is astronomy catalog data. It does not include object imagery.
